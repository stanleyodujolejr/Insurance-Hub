# Insurance-Hub

Static study pages for life and health licensing practice.

**Published from `main` today:** Virginia and Maryland exam pages, linked from `index.html`. Progress stays in the browser. Optional progress sending on those two pages uses a report service that is not stored in this repository.

**This branch, not the published site until it is merged and the Pages site is updated:** Georgia practice for Pearson VUE 12-GA-01, 12-GA-02, and 12-GA-05. Sources, weights, and what was not verified are in `GEORGIA_SOURCES.md`. Georgia uses the same opt-in progress send. The Apps Script change that stores Georgia rows is proposed in `APPS_SCRIPT_GA_SETUP.md` and is not deployed from this repository.

`STUDY_PLAN.md` is the Maryland and Virginia study handoff. It is not a Georgia plan.
